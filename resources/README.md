# アプリアイコンの元画像

ここに **`icon.png`（1024×1024 / 透過なし / 角丸なし）** を1枚置くと、
Codemagic のビルド時に iOS 用の全サイズのアイコンが自動生成されます。

- 無い場合：Capacitor のデフォルトアイコンでビルドされます（App Store 審査で差し替えが必要）。
- 作り方：Figma / Canva / Keynote などで 1024×1024 の正方形を書き出すだけ。
  背景は塗りつぶし（例：`#16181C` に白文字「R2L」）。
- 任意で `splash.png`（2732×2732）を置くと起動画面も生成されます。
